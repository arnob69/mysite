FAQ 16:9 / 9:16 Interactive Accordion

High-contrast, minimal dark container housing disclosure list items with custom 1:1 square indicators, hover-trigger expansion, single-open constraints, and strict vertical text alignment.

• Aspect Ratio: 16:9 on desktop (.faq_box_16_9) / 9:16 on mobile (≤768px)
• Square Indicator: 1:1 ratio (18px × 18px), matching question font height
• Active States: Inactive: rgba(255,255,255,0.2) / Hover & Open: var(--color_W)
• Hover Behavior: mouseenter automatically activates & expands item
• Text Alignment: Answer padding matches question text start (58px offset)
• Single Open: name="faq-group" + JS toggle sync

// 16:9 Code Snippet Box Line Number Auto-Generator function initCodeBoxes(scope = document) { const boxes = scope.querySelectorAll('.code_box_16_9'); boxes.forEach(box => { if (box.dataset.codeBoxSetup) return; box.dataset.codeBoxSetup = 'true'; const codeEl = box.querySelector('.code_content code') || box.querySelector('code'); if (!codeEl) return; let lineNumbersEl = box.querySelector('.code_lines'); const bodyEl = box.querySelector('.code_box_body') || box; if (!lineNumbersEl && bodyEl) { lineNumbersEl = document.createElement('div'); lineNumbersEl.className = 'code_lines'; bodyEl.insertBefore(lineNumbersEl, bodyEl.firstChild); } const lines = codeEl.textContent.trim().split('\n'); lineNumbersEl.innerHTML = lines.map((_, i) => i + 1).join('
'); }); }

Crafting a Minimalist Portfolio: Figma Design & Frontend Architecture

When starting this project in Figma, the primary goal was to establish a high-contrast yet comfortable color palette that translates seamlessly between light and dark modes. Rather than relying on rigid static colors, I built a fluid token structure using light-dark primitives.

Pure blacks (#000) and pure whites (#fff) form the foundation, paired with subtle 60% and 80% opacity variations (`--color_B_60`, `--color_B_80`) to establish a clear visual hierarchy for secondary typography, borders, and icon strokes.

2. Typography & Spatial Rhythm

Typography plays a critical role in readability. For headings, interactive links, and buttons, Inter provides structured geometric clarity. For long-form body text and descriptive paragraphs, Andika offers optimal legibility and generous character spacing.

The layout spatial grid relies on generous section gaps (200px on desktop scaling down to 80px on mobile) to give every visual element breathing room without cluttering the user interface.

3. Building Clean, Framework-Free Frontend Code

The entire frontend was built using semantic HTML5 elements and modular CSS without heavyweight frameworks. Components like the sticky header, mobile overlay drawer, and card grids were engineered for lightweight performance and sub-second load times.
